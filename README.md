# Training - Workout Tracker Application

A simple, self-contained workout tracking application to log your weekly exercises with kilograms, reps, and sets.

## Features

- 📅 **Weekly Schedule**: Track workouts for each day of the week (Monday-Sunday)
- 💪 **Exercise Logging**: Log kilograms, reps, and sets for each exercise
- 📊 **Data Persistence**: Your workout data is automatically saved in your browser
- 🗓️ **Week Navigation**: Navigate between different weeks to view past or plan future workouts
- 📱 **Responsive Design**: Works on desktop, tablet, and mobile devices

## How to Use

1. Open `index.html` in your web browser
2. Select a day of the week from the buttons
3. Enter your workout data (kilograms, reps, sets) for each exercise
4. Data is automatically saved as you type
5. Use the week navigation buttons to view different weeks

## Technical Details

- Pure HTML, CSS, and JavaScript (no dependencies required)
- Uses localStorage for data persistence
- Responsive design with modern UI/UX
- Works offline once loaded

## Installation

Simply clone this repository and open `index.html` in your browser:

```bash
git clone https://github.com/lili-wellness/Training-.git
cd Training-
open index.html  # or double-click the file
```

No build process or dependencies required!
